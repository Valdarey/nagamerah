# Installation
Linux only. Kali/Debian/Ubuntu recommended. Python 3.10+, pipx, git. Run `./install.sh`; installer uses pipx, does not use sudo pip, and does not collect API keys. For development: `python3 -m venv .venv`, activate, then `pip install -e '.[dev]'`. Uninstall: `pipx uninstall nagamerah`.
